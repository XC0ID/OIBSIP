# 🌟 OIBSIP – Data Science Internship Projects

This repository contains all the projects completed during the **Oasis Infobyte Data Science Internship (OIBSIP)**.  
It demonstrates practical implementation of machine learning concepts on real-world datasets.

---

## 📌 Repository Overview

This repository includes the following 4 major projects:

1. 🌸 Iris Flower Classification  
2. 📊 Sales Prediction  
3. 📧 Spam Classification  
4. 📉 Unemployment Rate Analysis  

Each project focuses on different machine learning techniques such as classification, regression, and data analysis.

## 🌸 1. Iris Flower Classification

- Predicts the species of iris flowers using machine learning algorithms  
- Based on features like sepal length, sepal width, petal length, and petal width  
- A classic beginner dataset with 3 classes: Setosa, Versicolor, Virginica :contentReference[oaicite:0]{index=0}  

### 🔧 Techniques Used:
- Classification Algorithms (Logistic Regression / KNN / Decision Tree)
- Data Visualization
- Model Evaluation

## 📊 2. Sales Prediction

- Predicts product sales based on advertising data  
- Helps businesses understand how advertising impacts revenue  

### 🔧 Techniques Used:
- Linear Regression
- Data Analysis (EDA)
- Feature Importance

## 📧 3. Spam Classification

- Classifies messages as **Spam or Not Spam**  
- Useful for email filtering systems  

### 🔧 Techniques Used:
- NLP (Natural Language Processing)
- Text Vectorization (TF-IDF / CountVectorizer)
- Classification Models (Naive Bayes, Logistic Regression)

## 📉 4. Unemployment Rate Analysis
